# 商务设计与报价

## 基本规则

- 价格、折扣、税率、付款、期限和承诺必须来自可靠材料或用户确认。
- 每一档方案统一展示产品/服务范围、数量、期限、原价、折扣、最终价格、税务口径、付款、赠送、有效期和不包含事项。
- 区分一次性费用、周期性费用、可选费用和赠送项。
- 赠送项写清内容、数量、期限、使用条件和到期后的处理方式。
- 续费、扩容、升级和超范围服务有规则时应明确；没有依据时不要自行承诺。

## 多档方案

基础、推荐、增强档应在范围或服务上有实质差异，不要只机械改变折扣。推荐档应说明推荐理由及适用前提。

## 税务口径

- 明确价格是否含税、税率、税种（材料提供时）以及单位。
- 含税价反算税额：`税额 = 含税价 × 税率 ÷ (1 + 税率)`。
- 未税价计算含税总额：`含税总额 = 未税价 × (1 + 税率)`。
- 税率未知时保留待确认，不得为了填满表格而猜测。

## 折扣与期间

- 行项目金额：`数量 × 单价 × 计费期间 × (1 - 折扣百分比/100)`。
- 明确单价是每套、每用户、每节点、每年、每项目还是每人天。
- 多年合同应区分年度费用与合同期总额。
- 免费/赠送项目的对外价值只有在存在可靠标准价时才展示。

## 付款与有效期

付款节点应与交付里程碑或合同约定相匹配。方案有效期、报价有效期、服务起止条件和续费起点不要混用。

## 结构化校验

将报价整理为 JSON 后可运行：

```text
python scripts/validate_quote.py quote.json
```

输入字段：

```json
{
  "currency": "CNY",
  "prices_include_tax": true,
  "tax_rate": "0.06",
  "tolerance": "0.01",
  "options": [
    {
      "name": "推荐方案",
      "items": [
        {
          "name": "平台授权",
          "quantity": "1",
          "unit_price": "100000",
          "periods": "1",
          "discount_percent": "10",
          "gift": false,
          "declared_line_total": "90000"
        }
      ],
      "declared_subtotal": "90000",
      "declared_tax": "5094.34",
      "declared_total": "90000"
    }
  ]
}
```

含税输入中 `declared_subtotal` 与 `declared_total` 均为含税金额；未税输入中 `declared_subtotal` 为未税小计，`declared_total` 为含税总额。脚本只校验算术一致性，不证明价格或税率经过授权。
